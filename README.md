# ☕ Кофейня «Зернышко» — Лендинг

Уютный одностраничный сайт для кофейни «Зернышко» с интерактивным меню, формой бронирования столиков и картой проезда. Проект выполнен для портфолио по верстке.

🔗 **[Посмотреть живой сайт (GitHub Pages)]((https://demish-code.github.io/zernyshko-coffee/))**

---

## ✨ Реализованный функционал

* **Фиксированная шапка и навигация:** липкий `header` и плавный скролл по якорным ссылкам с учетом высоты шапки (`scroll-margin-top`).
* **Интерактивное меню (табы на JS):** мгновенное переключение между категориями («Кофе», «Десерты», «Закуски») без перезагрузки страницы.
* **Микро-анимации на CSS:** плавный поворот элементов на столе в первом экране (`transform: rotate`) и масштабирование изображений в карточках при наведении.
* **Форма бронирования:** валидация полей, перехват отправки на JavaScript с выводом уведомления об успешной броне и автоматической очисткой формы.
* **Интерактивная карта:** встроенный виджет карты с меткой расположения кофейни.

---

## 🛠 Стек технологий

* **HTML5** — семантическая разметка.
* **SCSS (CSS3)** — переменные, вложенность, Flexbox и CSS Grid.
* **БЭМ** — чистая и масштабируемая архитектура классов.
* **JavaScript (ES6+)** — работа с DOM, событиями и классами (`querySelectorAll`, `addEventListener`, `classList`).
